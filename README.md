# 독도까지 (배 키우기)

2017년 Zzoo의 모바일 게임 「DOKDO」(독도까지 배 키우기)를 기억하며 브라우저용으로 다시 만든 비공식 팬 제작 게임입니다.
원작의 그림, 3D 모델, 소리는 쓰지 않았습니다. 모든 모델과 효과음은 코드로 새로 만들었습니다.

## 플레이

`index.html`을 웹 서버로 열면 됩니다. 휴대폰과 PC 브라우저 모두 됩니다.

```
python3 -m http.server 8000   # 그다음 http://localhost:8000
```

GitHub Pages를 켜면(Settings → Pages → Branch: master, / (root)) `https://<계정>.github.io/toss/`에서 바로 할 수 있습니다.

## 게임 방법

- **조종**: 바다를 누른 채 끌면 그 방향으로 항해합니다. 손을 떼면 멈추고, 두 번 탭하면 계속 항해합니다. PC는 방향키나 WASD도 됩니다.
- **전투**: 대포는 배 옆구리에 있습니다. 적을 배 옆쪽에 두면 자동으로 쏩니다.
- **섬 점령**: 섬에 다가가면 방어 함대가 나옵니다. 모두 격침하면 점령됩니다. 후퇴했다 돌아와도 이미 격침한 배는 되살아나지 않습니다.
- **정박소**: 점령한 섬 부두에서 수리하고 선체·돛·조타·대포·낚시를 강화합니다. 선체 레벨이 다른 강화의 상한입니다.
- **시장**: 섬마다 시세가 다르고 10분마다 바뀝니다. 싸게 사서 비싼 섬에 팔 수 있습니다.
- **조수**: 호위선, 갈매기(회복), 네시(최대 체력), 돌고래(전리품·속도).
- **낚시**: 점령한 섬 근처, 적이 없을 때 할 수 있습니다.
- **아레나**: 웨이브 생존 도전. 침몰해도 짐을 잃지 않습니다.
- **목표**: 태평양 8개 섬을 점령하면 대서양이 열리고, 대서양 끝의 독도에서 크라켄을 물리치면 엔딩입니다.

진행 상황은 브라우저에 자동 저장됩니다. 설정에서 저장 데이터를 복사해 다른 기기로 옮길 수 있습니다.

## 구조

- `index.html` 화면과 스타일
- `js/game.js` 게임 루프, 전투, AI, 저장
- `js/ui.js` HUD, 섬 메뉴, 지도
- `js/models.js` 로우폴리 3D 모델
- `js/data.js` 섬·적·강화·교역 수치
- `js/audio.js` 효과음 합성
- `js/three.module.min.js` three.js r160 (MIT)
- `replica/` 원작 조사 기록
