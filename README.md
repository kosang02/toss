# 독도까지 (배 키우기)

2017년 Zzoo의 모바일 게임 「DOKDO」(독도까지 배 키우기)를 브라우저용으로 다시 만든 비공식 팬 제작 게임입니다.
원작 APK를 분석해 게임 규칙, 수치, 섬 위치를 가져왔습니다. 원작의 그림, 3D 모델, 소리, 코드는 쓰지 않았고 모두 새로 만들었습니다.

## 플레이

`index.html`을 웹 서버로 열면 됩니다. 휴대폰과 PC 브라우저 모두 됩니다.

```
python3 -m http.server 8000   # 그다음 http://localhost:8000
```

GitHub Pages를 켜면(Settings → Pages → Branch: master, / (root)) `https://<계정>.github.io/toss/`에서 바로 할 수 있습니다.

## 게임 방법

원작 APK를 분석해 규칙과 수치를 그대로 옮겼습니다. 자세한 내용은 [replica/original-system.md](replica/original-system.md)에 있습니다.

- **조종**: 드래그한 방향으로 배가 힘을 받아 나아갑니다(관성 있음). 두 번 탭하면 화면 중심에서 그 방향으로 자동 항해합니다. PC는 방향키나 WASD.
- **전투**: 배 옆구리의 포탑이 옆에 온 적을 자동으로 조준해 2.8초마다 쏩니다. 적과 부딪혀도 피해를 줍니다.
- **섬 점령**: 독도 해역 섬 28개, 이탈리아 섬 19개. 섬 가까이 가면 수비대가 나오고, 모두 격침하면 점령됩니다. 점령한 섬에 닿으면 자동으로 정박합니다.
- **선착장**: 선체(최대 10), 돛·선회·대포·낚시(선체 레벨×5, 최대 50) 강화. 정박 중에는 체력이 회복됩니다.
- **시장**: 섬 등급별 가격과 재고, 10분마다 재고 초기화.
- **조수**: 호위선 3척, 갈매기 2마리, 네시, 줍줍 보트.
- **낚시**: 점령한 섬 근처에서 자동으로 낚시합니다.
- **독도**: Lv.10 해적이 끝없이 몰려오는 특별 해역. 크라켄이 바다 곳곳에 숨어 있습니다.
- **아레나**: 해적 웨이브를 막고 격침 수만큼 보상.
- 침몰해도 짐은 잃지 않습니다. 마지막 섬으로 돌아가거나, 부활권이나 코인으로 그 자리에서 부활합니다.

진행 상황은 브라우저에 자동 저장됩니다. 설정에서 저장 데이터를 복사해 다른 기기로 옮길 수 있습니다.

## 구조

- `index.html` 화면과 스타일
- `js/game.js` 게임 루프, 전투, AI, 저장
- `js/ui.js` HUD, 섬 메뉴, 지도
- `js/models.js` 로우폴리 3D 모델
- `js/data.js` 강화·적·시장·보상 공식 (원작 수치)
- `js/world.js` 섬 47개, 독도, 아레나, 크라켄 좌표 (원작 씬에서 추출)
- `js/audio.js` 효과음 합성
- `js/three.module.min.js` three.js r160 (MIT)
- `replica/original-system.md` 원작 시스템 분석
- `replica/` 원작 조사 기록
